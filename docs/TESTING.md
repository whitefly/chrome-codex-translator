## 尚需手工验收

尚未在用户日常 Chrome 配置中加载扩展并完成真实 Native Messaging 端到端测试。上面的浏览器测试模拟了 Chrome 通信边界，不能替代扩展实际安装测试。

手工步骤：

1. Chrome 加载 extension，确认 ID 与注册清单一致。
2. 打开普通 HTTPS 网页，点击扩展、连接 Codex。
3. 划词后翻译，确认看到逐步更新；复制译文。
4. 元素模式选择段落，↑ 扩大范围，点击选定；Esc 取消。
5. 截图模式框选文字，检查预览位置与内容，提交并查看结果。
6. 开始长文本翻译后停止，随后重新发起翻译。
7. 切换模型和语言，重开侧边栏检查偏好。
8. Chrome 限制页面、跨域 iframe、网络断开和额度不足时应显示可理解的错误。

尚未覆盖：Intel Mac、Windows/Linux 原生注册、Chromium/Edge、所有网页缩放组合、iframe 和复杂 Shadow DOM、长时间休眠后重连。初版不支持滚动长截图与整页替换译文。
